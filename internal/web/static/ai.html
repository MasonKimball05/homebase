Use it from Loom

Loom's Local AI view can read and edit your project with these models, asking you before every change.

  1. In Loom, open Settings (⌘, on a Mac, Ctrl+, on Windows) and find Local AI.
  2. Set the host to this address: …
  3. Open the Local AI view in the activity bar and pick a model.

Works from any of your devices on Tailscale. Use a model with tool support (qwen3-coder, gpt-oss) so it can open files; others can still chat.

Use it from other tools

Anything that speaks Ollama's API and lets you set a base URL can use it. Homebase passes on four endpoints:

GET /api/version
Ollama's version: is it up
GET /api/tags
The models on this PC
GET /api/ps
Which are loaded now, and how much is on the GPU
POST /api/chat
A chat, streamed. Send the header X-Homebase: 1; browsers on other sites are refused.
